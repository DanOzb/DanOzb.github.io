# Personal Portfolio

My personal site, live at [DanOzb.github.io](https://DanOzb.github.io).

Built with [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/), 
based on the [devportfolio](https://github.com/RyanFitzgerald/devportfolio) template 
by Ryan Fitzgerald (MIT licensed).

## Local development

```bash
npm install
npm run dev
```

## Deployment

Auto-deployed to GitHub Pages via GitHub Actions on every push to `main`.
